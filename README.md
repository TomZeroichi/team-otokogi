# TEAM狭気 — みんなで共有する男気じゃんけん成績アプリ

スマートフォンで使える、**勝負・おごり・累計金額・ランキング・次回ルール決定権**の共有Webアプリです。

## 現在の仕様（v0.2）

- **男気ルール**：最終勝者が会計全額を支払う。
- **通常ルール**：最終敗者が会計全額を支払う。
- **次回ルール選択権**：いずれのルールでも「今回の最終敗者」に移る。本人のアカウントからしか変更できない。
- **初回のルール選択**：グループの作成者（管理者）が決める。
- **勝負の記録**：開催日・店名・金額・参加者・最終勝者・最終敗者・メモ。支払者はルールから自動計算。
- **過去の戦績**：管理者がルールを直接選び「過去の記録」として追加できる。次回のルール選択権には影響しない。
- **ランキング**：総支払額 / 損得（割り勘換算差額） / 勝率 / 奢られ額（割り勘相当額） / 敗戦数。
- **和風UI（v0.2）**：参考画像に沿った黒×金×朱色の和風デザイン。赤い日の丸・富士山・青海波・金の見出し・生成り色の入力パネル。ホーム／ランキング／記録／分析／メンバーの固定5メニュー。開催履歴はメニューと記録画面から開けます。
- **ダッシュボード**：累計支払額、開催回数、一人当たり支払額、今月の支払額、登録メンバー、月別推移。
- **履歴管理**：管理者は履歴を削除可能。通常の対戦は最新記録から順に削除する仕様。
- **共有**：招待URLをLINEグループへ送信。各自、名前＋6桁暗証番号で初回登録し、以後ログイン。
- **同期**：画面を表示中は約20秒ごとに最新データを取得。フォーム編集中は入力内容の保護を優先。

**注意**：初期版は1対戦につき「最終勝者が1名」「最終敗者が1名」「会計を支払う人が1名」というルールです。引き分けや複数の支払者、複数の最終敗者は未対応です。プロフィール編集や暗証番号再発行も未搭載です。

## Windowsで動かす

1. Python 3.11以降をインストールする。
2. このZIPを展開する。
3. `start.bat` をダブルクリックする。
4. PCで `http://localhost:8000/` を開く。

データは同じフォルダーの `data/kyoki.sqlite3` に保持されます。このURLはローカル接続用なので、**そのままでは別の家や外出先の友人には共有できません**。

## macOS / Linuxで動かす

```bash
./start.sh
# http://localhost:8000/
```

## Dockerで動かす

```bash
docker build -t team-otokogi .
docker run --rm -p 8000:8000 -v kyoki-data:/data -e COOKIE_SECURE=0 team-otokogi
```

`-v kyoki-data:/data` を外すとコンテナ停止時にデータが失われる可能性があるので必ず指定してください。

## LINEグループ全員で使えるように公開する場合

1. GitHubの新しいリポジトリ（例：`team-otokogi`）へ、このソースをアップする。
2. RailwayなどのHTTPSでWebアプリを公開できるホスティングに接続し、Dockerfileを使ってデプロイ。
3. **必ず永続ボリュームを作り、マウント先を `/data` に設定**する。これがないとアプリ更新時に記録が消える可能性があります。
4. 本番環境では `COOKIE_SECURE=1` とし、HTTPSでアクセスする。
5. 公開URLから管理者が「TEAM狭気」グループを作成し、メンバー画面の「LINEで招待リンクを共有」を押す。
6. グループ参加者は各自、自分の名前・6桁暗証番号で登録する。

> デプロイ自体はこのZIPには含まれていません。公開サーバーと永続ディスクを用意する必要があります。Railway等では利用料金が発生する場合があります。GitHub Pagesのような静的ホスティングだけでは、共有用のデータベースサーバーが動きません。

## ランキングの計算について

1. **支払総額** = 支払者として登録された各会計の金額の合計。
2. **割り勘相当額** = 自分が参加した対戦の会計金額 ÷ その対戦の参加人数、の合計。
3. **損得** = 割り勘相当額 − 支払総額。プラスなら割り勘より得をしている。
4. **奢られ額** = 自分が支払者ではなかった対戦の割り勘相当額の合計。
5. **勝率** = 最終勝者となった回数 ÷ 参加回数 × 100。

この指標は集計用の目安です。食べた量や飲んだ量に応じた公平性を保証するものではありません。

## テスト

```bash
python -m pip install -r requirements.txt
python -m pip install pytest httpx
python -m pytest -q
```

### ファイル構成

- `app.py` : FastAPI + SQLite の共通データ・会員登録・ルール権限・対戦履歴API
- `static/index.html` : スマートフォン対応HTML
- `static/style.css` : スマートフォン和風UI
- `static/app.js` : 画面制御・ランキング・API連携
- `static/hero.svg` / `static/waves.svg` : 和風背景素材
- `static/manifest.webmanifest` / `static/icon-*` : ホーム画面追加用アイコン
- `requirements.txt` : 実行に必要な依存関係
- `Dockerfile` : 公開ホスティング向け設定
- `start.bat` / `start.sh` : ローカル起動スクリプト
- `tests/test_app.py` : 自動テスト

## セキュリティ・運用メモ

- 参加には高強度のランダムな招待URLが必要です。**LINEグループ外に共有しないでください**。
- 暗証番号はハッシュ化して保存されます。URLに暗証番号は付けません。
- 匿名投稿を許さず、参加者ごとにログインして記録します。通常記録はログインメンバーが登録でき、履歴の削除と過去データの登録は管理者のみです。
- 「6桁の暗証番号」は簡易認証です。機密情報を入れないでください。金融決済には使用しないでください。
- 管理者はDBファイルを安全な場所に定期バックアップしてください。
- 一般公開する本番運用にはHTTPS・バックアップ・サービス稼働監視・不正アクセス対策を推奨します。
